# 💻 C-Programming Practice & Algorithms

이 폴더는 로봇 및 임베디드 제어의 근간이 되는 **C 언어의 문법을 완벽히 숙달**하고, 주어진 요구사항을 코드로 구현해 내는 **논리적 알고리즘 설계 능력**을 기르기 위한 학습 기록입니다.

## 📌 학습 목표
- **문법의 내재화:** 변수와 제어문부터 배열, 포인터, 구조체에 이르는 C 언어 핵심 문법을 암기가 아닌 체득을 통해 이해합니다.
- **메모리 및 구조 이해:** 포인터 연산과 동적 할당을 직접 다루며 저수준(Low-level)에서의 데이터 흐름을 통제하는 역량을 확보합니다.
- **문제 해결 능력:** 챕터별 다양한 예제와 테스트 코드를 구현하며, 알고리즘을 설계하고 디버깅하는 코딩 기초 체력을 기릅니다.

---

## 📂 폴더 구조 및 주요 내용

### 1. `text_book` (일자별 기초 실습)
- 매일 진행된 C 언어 기본기 훈련 코드입니다.
- **주요 내용:** 입출력 기초, 연산자, 반복/조건문, 함수 설계, 1차원/2차원 배열 활용
- 각 일차 마지막에는 `test.c` 및 `exam.c` 파일을 통해 스스로의 논리 전개 방식을 점검했습니다.

### 2. `skill_book` (심화 문법 및 알고리즘 적용)
- 포인터와 메모리 개념이 본격적으로 도입된 심화 문제 풀이 공간입니다.
- **주요 내용:** 다중 포인터, 구조체(Struct) 배열, 문자열 처리 최적화, 파일 입출력(I/O) 제어
- 복잡한 데이터 구조를 직접 설계하고 접근하는 훈련을 진행했습니다.
- `Makefile`을 이용한 다중 파일 컴파일 및 빌드 자동화
- TCP/IP 소켓(Socket) 기반의 데이터 송수신 실습

## 🛠 실행 및 컴파일 (Compilation)

대부분의 소스 코드는 Linux(Ubuntu) 환경의 터미널에서 `gcc`를 통해 빌드할 수 있도록 작성되었습니다.

```bash
# 단일 파일 컴파일 예시
gcc -o result day10.c

# 실행
./result
```
